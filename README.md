Настольное приложение для учёта и анализа физических упражнений, разработанное на Python с использованием tkinter для графического интерфейса.

## Описание

Планер физических упражнений — это полнофункциональное приложение для управления тренировками, которое позволяет:

- Регистрировать выполненные упражнения с указанием типа, веса, количества подходов и повторений
- Хранить данные о дате выполнения и комментариях
- Просматривать, фильтровать и сортировать упражнения
- Анализировать прогресс по весу
- Рассчитывать общий объем работы
- Экспортировать данные в различные форматы (CSV, JSON)
- Визуализировать данные о тренировках (графики прогресса, структура нагрузки, максимальные веса)
- Управлять данными через удобный графический интерфейс

## Использование

### Основные функции

- Добавление упражнения

- Просмотр упражнений

- Удаление упражнения

#### Анализ данных

Приложение предоставляет несколько инструментов для анализа:

- **Прогресс по весу** — показывает динамику веса для выбранного упражнения
- **Круговая диаграмма объема** — отображает распределение объема работы по типам упражнений
- **Максимальные веса** — столбчатая диаграмма максимальных весов по типам упражнений
- **Динамика объема** — график изменения общего объема работы по времени

#### Экспорт данных

- **Экспорт в CSV**: Файл → Экспорт в CSV...
- **Экспорт в JSON**: Файл → Экспорт в JSON...

### Форматы данных

#### CSV формат

CSV файлы должны содержать следующие столбцы:
- `exercise_id` — уникальный идентификатор упражнения
- `exercise_type` — тип упражнения
- `weight` — используемый вес в килограммах
- `sets` — количество подходов
- `reps` — количество повторений
- `date` — дата в формате ISO (YYYY-MM-DDTHH:MM:SS)
- `comment` — комментарий к упражнению

## Архитектура

### Модули

#### models.py

Содержит класс для представления данных:

- **Exercise**: Физическое упражнение с весом, подходами, повторениями, датой и комментарием

#### storage.py

Класс `DataStorage` отвечает за:

- Сохранение и загрузку данных из CSV файлов
- Добавление, удаление и получение упражнений
- Фильтрацию упражнений по типу и дате
- Экспорт данных

#### analysis.py

Класс `ExerciseAnalyzer` предоставляет:

- Расчет общего объема работы
- Анализ данных по типам упражнений
- Расчет максимальных весов
- Построение графиков и диаграмм (matplotlib, seaborn)

#### gui.py

Класс `ExercisePlannerGUI` создает:

- Графический интерфейс на основе tkinter
- Формы для ввода данных упражнений
- Таблицы для отображения упражнений
- Кнопки для управления и анализа
- Меню для экспорта данных

#### utils.py

Вспомогательные функции:

- Валидация данных с использованием регулярных выражений
- Очистка и форматирование строк
- Проверка корректности веса, подходов, повторений, типов упражнений
